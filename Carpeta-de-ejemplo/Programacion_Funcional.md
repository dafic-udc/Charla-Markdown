# Programación Funcional

## Características
- **Inmutabilidad**: Los datos no cambian una vez creados.
- **Funciones de Orden Superior**: Funciones que reciben o devuelven otras funciones.
- **Pureza**: Funciones sin efectos secundarios.

## Operaciones Comunes
- `map`: Transforma cada elemento.
- `filter`: Filtra elementos según un predicado.
- `reduce`: Combina elementos en un solo valor.
