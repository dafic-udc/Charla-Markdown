# Sistemas Operativos

## Gestión de Procesos
- **Proceso**: Programa en ejecución.
- **Hilo (Thread)**: Unidad básica de utilización de la CPU dentro de un proceso.
- **Planificación (Scheduling)**: Algoritmos como Round Robin, FIFO, o Prioridades.

## Memoria Virtual
Permite ejecutar procesos que requieren más memoria de la físicamente disponible mediante el uso de **Paginación** y **Segmentación**.
