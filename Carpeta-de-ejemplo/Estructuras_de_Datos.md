# Estructuras de Datos

## Listas Enlazadas vs Arrays
- **Arrays**: Acceso O(1), inserción O(n) en el peor caso.
- **Listas Enlazadas**: Acceso O(n), inserción O(1) si se tiene el puntero.

## Árboles Binarios de Búsqueda (BST)
Para todo nodo `n`:
- Valores en subárbol izquierdo < `n.valor`
- Valores en subárbol derecho > `n.valor`
