# Sistemas Distribuidos

## Conceptos Fundamentales
- **Transparencia**: El usuario no percibe que el sistema está compuesto por múltiples máquinas.
- **Escalabilidad**: Capacidad de manejar el crecimiento añadiendo recursos.

## Teorema CAP
En un sistema distribuido, solo puedes garantizar dos de estas tres:
1. **C**onsistency (Consistencia)
2. **A**vailability (Disponibilidad)
3. **P**artition Tolerance (Tolerancia a particiones)
