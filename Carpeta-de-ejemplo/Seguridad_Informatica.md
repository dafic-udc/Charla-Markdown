# Seguridad Informática

## Criptografía
- **Simétrica**: Misma clave para cifrar y descifrar (ej. AES).
- **Asimétrica**: Clave pública para cifrar, clave privada para descifrar (ej. RSA).

## Principios CIA
- **Confidencialidad**: Solo usuarios autorizados acceden.
- **Integridad**: Los datos no se modifican sin permiso.
- **Disponibilidad**: El sistema está accesible cuando se necesita.
